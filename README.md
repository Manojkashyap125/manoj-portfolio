## ✨ POWERS & FEATURES

- 🖱️ **Click anywhere** → `THWIP!` `POW!` `ZAP!` bursts explode at your cursor
- 🚨 **Spider-signal** → flashes the whole screen white + confirmation toast
- 📄 **Live PAGE x/4 tracker** in the sticky issue-index nav
